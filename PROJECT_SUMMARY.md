## 🔧 Common Customizations

### Change Colors
Edit CSS variables in `styles.css` (lines 2-18):
```css
:root {
    --primary-color: #6366f1; /* Your brand color */
    --secondary-color: #8b5cf6;
    /* ... more colors */
}
```

### Add More Projects
Copy a project card in `index.html` and modify:
```html
<div class="project-card">
    <!-- Update title, description, tags, links -->
</div>
```

### Adjust Animation Speed
Change the `--transition` variable in `styles.css`:
```css
--transition: all 0.3s ease; /* Faster = 0.2s, Slower = 0.5s */
```

### Change Particle Count
Edit `script.js` line 27:
```javascript
value: 80, // More = 120, Less = 40
```
